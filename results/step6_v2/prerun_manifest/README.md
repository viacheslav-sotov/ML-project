# Step 6 v2 pre-run manifest

`manifest_prerun_v2.json` was written with `experiments/unsw_step6_manifest.py` for protocol `step6-v2` **before any v2 experiment**. It records the starting state: protocol hash, data and model hashes, code hashes, split, flows, seeds, LIME configuration and software versions, at Git commit 69a1cda (clean tree).

It is **not** a result. Each v2 run writes its own manifest into its run folder.
